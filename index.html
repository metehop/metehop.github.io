Sources & modèles utilisés

Cette application n'invente aucune donnée. Voici l'ensemble des sources, modèles météorologiques, jeux de données et bibliothèques réellement utilisés.

Prévisions & données météo

Open-Meteo — API Forecast Prévisions horaires/journalières jusqu'à 16 jours (température, vent, précipitations, nébulosité, neige, vent en altitude 200hPa...), agrégées à partir de modèles météorologiques publics (dont ICON de DWD, GFS de NOAA, ECMWF selon la région). open-meteo.com
Open-Meteo — API Archive (historique) Données journalières réelles passées (jusqu'à 20 ans), utilisées pour calculer les normales de saison par quinzaine. open-meteo.com/historical-weather-api
Open-Meteo — API Marine Hauteur de houle, température de l'eau et conditions marines. open-meteo.com/marine-weather-api
Open-Meteo — API Geocoding Recherche et résolution des noms de lieux en coordonnées. open-meteo.com/geocoding-api

Pollution & pollens

Open-Meteo — API Air Quality Indice de qualité de l'air et concentrations de pollens (modèle CAMS/Copernicus), jusqu'à 7 jours pour la pollution, ~4 jours pour les pollens (Europe uniquement). open-meteo.com/air-quality-api
European Air Quality Index (EAQI) Échelle officielle de l'Agence européenne pour l'environnement (EEA) utilisée pour convertir l'indice en catégories Bon/Correct/Moyen/Mauvais/Très mauvais/Extrême. airindex.eea.europa.eu
Seuils de risque pollens (EAN / CAMS) Seuils par type de pollen (grains/m³) issus des travaux du European Aeroallergen Network et de la classification CAMS/SILAM, utilisés pour la catégorie Faible/Modéré/Élevé/Très élevé. climate-adapt.eea.europa.eu

Température sol & air (plantations)

Open-Meteo — API Forecast Température de l'air (2m) et température du sol en surface (0cm), prévisions réelles sur 16 jours. open-meteo.com/docs
Open-Meteo — API Archive (ERA5 / ERA5-Land) Moyennes historiques réelles calculées sur les 15 dernières années pour les mêmes dates calendaires, pour l'air (2m) et le sol (0-7cm, couche la plus proche disponible dans l'historique). open-meteo.com/historical-weather-api

Stations de ski & géographie

OpenStreetMap — Overpass API Localisation des domaines skiables réels nommés (landuse=winter_sports) dans un rayon de 60km. overpass-api.de
Nominatim (OpenStreetMap) Recherche de lieux (ex. plages / stations balnéaires les plus proches). nominatim.openstreetmap.org
Skiinfo / Météo-France Ski et Neige (liens uniquement) Non intégrés : l'API temps réel de Skiinfo (OnTheSnow/Mountain News) est payante avec clé requise ; le réseau Nivo-météo en accès libre de Météo-France (stations de mesure de neige en montagne) a été fermé — le fichier officiel testé ne répond plus. skiinfo.fr / meteofrance.com/meteo-montagne

Radar & carte

RainViewer Tuiles radar de précipitations en temps réel. rainviewer.com/api
Leaflet Bibliothèque JavaScript de cartographie interactive. leafletjs.com

Astronomie

SunCalc.js Calcul du lever/coucher du soleil, crépuscules civil/nautique/astronomique, position et illumination de la Lune — basé sur les formules de Jean Meeus (Astronomical Algorithms). github.com/mourner/suncalc
Seeing estimé Estimation indicative (secondes d'arc) basée sur le vent réel Open-Meteo à 200hPa (niveau du jet-stream) — pas une prévision de seeing scientifique de précision.
